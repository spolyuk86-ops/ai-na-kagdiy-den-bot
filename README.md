## 🚀 БЫСТРЫЙ СТАРТ (30 минут)

### 1. Получить токен и ID

```bash
# Telegram BotFather
1. Найти @BotFather
2. /newbot
3. Назвать: "AI Channel AutoBot"
4. Скопировать токен

# Ваш ID
1. @userinfobot
2. Узнать свой ID
```

### 2. Клонировать проект

```bash
git clone https://github.com/YOUR_USERNAME/ai-telegram-channel.git
cd ai-telegram-channel
pip install -r requirements.txt
```

### 3. Заполнить .env

```bash
cp .env.example .env

# Отредактировать:
BOT_TOKEN=123456789:ABCdefGHIjklmnoPQRstuvWXYZ...
CHANNEL_ID=-1001234567890
ADMIN_ID=123456789
```

### 4. Тест локально

```bash
python autopost_bot_v2.py
```

### 5. Развернуть на Railway

```bash
git push origin main
# Railway автоматически задеплоится
```

**Готово! Бот работает 24/7! 🎉**

## ⚡ ЧАСТЫЕ ВОПРОСЫ

### Q: Как часто обновлять контент?
**A:** Рекомендуется добавлять 10+ новых постов еженедельно.

### Q: Могу ли я поменять время постов?
**A:** Да! Отредактируйте `POSTING_TIMES` в `autopost_bot_v2.py`

### Q: Потеряются ли мои данные при редплое?
**A:** Нет, если вы настроили Volume на Railway. Если нет - потеряются.

### Q: Как увеличить доход?
**A:** 
1. Добавьте больше affiliate партнёров
2. Увеличьте качество контента

## 🔒 БЕЗОПАСНОСТЬ

### Best Practices:

1. **Никогда не сохраняйте BOT_TOKEN в коде!**
   ```python
   # ❌ НЕПРАВИЛЬНО:
   BOT_TOKEN = "123456789:ABCDEF..."
   
   # ✅ ПРАВИЛЬНО:
   BOT_TOKEN = os.getenv("BOT_TOKEN")
   ```

2. **Используйте .env для локального развития**
   ```bash
   # .env никогда не загружается в Git!
   ```

3. **Если токен компрометирован:**
   - Немедленно запустите `/revoke` в BotFather
   - Создайте нового бота
   - Обновите токен на Railway
