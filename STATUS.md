# Статус проєкту

Перевірено 2026-10-28.

## Поточний стан

- Репозиторій доступний і містить основний код бота.
- GitHub Actions workflow runs: 0.
- Каталог `.github/workflows` відсутній у поточній гілці `main`.
- Отже, GitHub Actions зараз не запускає бота автоматично.
- Для автоматичної роботи потрібен окремий процес запуску: хостинг/worker, cron або GitHub Actions workflow.

## Що перевірити перед запуском

1. Значення змінних із `.env.example`.
2. Telegram bot token і права бота в каналі.
3. Команду запуску з `Procfile`.
4. Залежності Python та працездатність основного entrypoint.
5. Логи після першого реального запуску.

Цей файл створено як контрольну точку, щоб не вважати репозиторій «працюючим» лише тому, що код присутній.
