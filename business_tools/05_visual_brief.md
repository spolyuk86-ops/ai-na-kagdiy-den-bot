# Конструктор продаючих візуалів

## Що це вирішує
Правки до дизайну займають дні, бо немає чіткого завдання.

**Формат:** готовий процес для малого бізнесу. **Час запуску:** 45–90 хвилин. **Результат:** одна повторювана задача має власника, шаблон і вимірювану дію.

## Впровадження сьогодні
1) Перед дизайном заповніть 6 полів: ціль, аудиторія, одна думка, факт, CTA, формат.
2) Згенеруйте 3 концепції.
3) Оберіть одну до запуску дизайну.
4) Перевірте текст на мобільному.

## Готовий AI-шаблон
```
Створи бриф для [формат] про [тема]. Аудиторія: [аудиторія]. Одна думка: [думка]. Підтверджений факт: [факт]. CTA: [cta]. Дай заголовок, структуру 5 слайдів, опис візуалу, не додавай неперевірених цифр.
```

## Воронка залучення → прогрів → продаж
Лідмагніт: “12 CTA для візуалів”. Продаж: конструктор + 10 брифів за 290 грн. Демонструйте один реальний бриф і готовий пост.

## Контроль і монетизація
Міряйте час від ідеї до публікації, кількість правок і переходи з останнього слайду.

## Чекліст перед запуском
- [ ] Факти, ціни та строки перевірені людиною.
- [ ] Є згода на email/повідомлення та можливість відписатися.
- [ ] Є один CTA і сторінка/інвойс оплати.
- [ ] Після покупки файл видається автоматично.
- [ ] Раз на тиждень переглядаються метрики та запити клієнтів.

**Не продавайте “AI”. Продавайте конкретно зекономлений час або контрольований результат.**
