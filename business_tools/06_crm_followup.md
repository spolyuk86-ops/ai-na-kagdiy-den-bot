# CRM + follow-up без менеджера

## Що це вирішує
Заявки з різних каналів губляться, а повторний контакт залежить від пам’яті.

**Формат:** готовий процес для малого бізнесу. **Час запуску:** 45–90 хвилин. **Результат:** одна повторювана задача має власника, шаблон і вимірювану дію.

## Впровадження сьогодні
1) Створіть таблицю з полями: дата, ім’я, канал, потреба, статус, наступна дія, дата.
2) Через Zapier/Make: нова форма → новий рядок → сповіщення в Telegram.
3) Щодня фільтруйте “дата follow-up = сьогодні”.
4) Не надсилайте повідомлення без згоди на комунікацію.

## Готовий AI-шаблон
```
Напиши follow-up для ліда, який питав про [послуга] [днів] днів тому. Контекст: [контекст]. До 55 слів: користь, одне питання, можливість відмовитись. Без фальшивої терміновості.
```

## Воронка залучення → прогрів → продаж
Лідмагніт: таблиця “не губити заявки”. Продаж: ця схема + готові статуси й 8 повідомлень за 490 грн. Просувайте кейсом “скільки заявок повернули за тиждень”.

## Контроль і монетизація
Міряйте: нові заявки, % з наступною дією, відповіді на follow-up, оплати. Не оцінюйте успіх кількістю відправлених повідомлень.

## Чекліст перед запуском
- [ ] Факти, ціни та строки перевірені людиною.
- [ ] Є згода на email/повідомлення та можливість відписатися.
- [ ] Є один CTA і сторінка/інвойс оплати.
- [ ] Після покупки файл видається автоматично.
- [ ] Раз на тиждень переглядаються метрики та запити клієнтів.

**Не продавайте “AI”. Продавайте конкретно зекономлений час або контрольований результат.**
