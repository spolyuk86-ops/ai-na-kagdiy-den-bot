# Карта 7 автоматизацій

## Що це вирішує
Команда копіює дані вручну між формою, чатами, таблицею та календарем.

**Формат:** готовий процес для малого бізнесу. **Час запуску:** 45–90 хвилин. **Результат:** одна повторювана задача має власника, шаблон і вимірювану дію.

## Впровадження сьогодні
1) Намалюйте процес від заявки до доставки.
2) Виберіть один вузол з найбільшою повторюваністю.
3) Запустіть простий сценарій: форма → CRM → задача → повідомлення.
4) Додайте ручну перевірку перед зовнішньою відправкою.

## Готовий AI-шаблон
```
Опиши автоматизацію для процесу [процес] у форматі: тригер, дані, дії, помилки, ручна перевірка, метрика. Інструменти: [інструменти]. Не пропонуй передавати персональні дані без згоди.
```

## Воронка залучення → прогрів → продаж
Лідмагніт: карта “де бізнес втрачає 5 годин”. Продаж: готова карта 7 сценаріїв за 490 грн; апсел — впровадження одного сценарію.

## Контроль і монетизація
Міряйте зекономлені хвилини на тиждень і кількість помилок. Автоматизуйте лише стабільний процес.

## Чекліст перед запуском
- [ ] Факти, ціни та строки перевірені людиною.
- [ ] Є згода на email/повідомлення та можливість відписатися.
- [ ] Є один CTA і сторінка/інвойс оплати.
- [ ] Після покупки файл видається автоматично.
- [ ] Раз на тиждень переглядаються метрики та запити клієнтів.

**Не продавайте “AI”. Продавайте конкретно зекономлений час або контрольований результат.**
