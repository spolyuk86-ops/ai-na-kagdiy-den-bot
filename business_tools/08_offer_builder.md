# Конструктор мініпродукту

## Що це вирішує
Експерт має знання, але продає лише години й не може масштабуватися.

**Формат:** готовий процес для малого бізнесу. **Час запуску:** 45–90 хвилин. **Результат:** одна повторювана задача має власника, шаблон і вимірювану дію.

## Впровадження сьогодні
1) Оберіть одну задачу, яку клієнт може закрити за 15–60 хвилин.
2) Упакуйте: результат, зміст, межі, приклад, ціна, спосіб отримання.
3) Проведіть 5 розмов до створення повної версії.
4) Зберіть оплату, лише тоді масштабуйте рекламу.

## Готовий AI-шаблон
```
Перетвори навичку [навичка] на мініпродукт для [аудиторія]. Дай 3 варіанти: результат, формат, зміст, межі, ціна-гіпотеза, тестовий CTA. Не обіцяй гарантований дохід.
```

## Воронка залучення → прогрів → продаж
Лідмагніт: “10 ідей мініпродукту для [ніша]”. Продаж: конструктор за 490 грн. Воронка: пост → лідмагніт → 3 листи → checkout → файл → запит відгуку.

## Контроль і монетизація
Міряйте: ліди, передзамовлення, конверсія checkout, повернення. Не створюйте великий курс до підтвердженого попиту.

## Чекліст перед запуском
- [ ] Факти, ціни та строки перевірені людиною.
- [ ] Є згода на email/повідомлення та можливість відписатися.
- [ ] Є один CTA і сторінка/інвойс оплати.
- [ ] Після покупки файл видається автоматично.
- [ ] Раз на тиждень переглядаються метрики та запити клієнтів.

**Не продавайте “AI”. Продавайте конкретно зекономлений час або контрольований результат.**
