# Профіль фрілансера, що продає

## Формула заголовка
**Допомагаю [ніша] отримати [результат] через [послуга]**. Приклад: «Допомагаю експертам підготувати 12 Telegram-постів за 3 дні».

## Блок “про мене”
1. Кому допомагаєте.
2. Який конкретний результат даєте.
3. Як відбувається робота: бриф → чернетка → правки → передача.
4. Що входить і що не входить.
5. CTA: «Напишіть “контент” — надішлю 2 ідеї для вашої ніші».

## 5 прикладів портфоліо без клієнтів
- Розбір відкритого профілю з позначкою “навчальний приклад”.
- Серія постів для вигаданого, але чітко позначеного бренду.
- До/після редагування власного тексту.
- Шаблон контент-плану.
- Один процес: бриф → результат.

## Ціни
Починайте з пакета, а не погодинної ставки. Наприклад: «10 постів — $50; 20 постів + план — $100». Ціна має відповідати вашому ринку, часу та податкам.

## Промпт для профілю
«Задай мені 7 питань про навички, нішу, докази й формат роботи. Потім напиши профіль до 900 символів українською, конкретно і без вигаданого досвіду.»

## Чекліст
- [ ] Є одна ніша або тип задачі.
- [ ] Результат зрозумілий за 5 секунд.
- [ ] Є 2–3 зразки.
- [ ] Є стартова ціна або спосіб її дізнатися.
- [ ] Є один наступний крок.
