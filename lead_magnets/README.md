Ці файли можна одразу видавати підписнику після email-підписки. Бот надсилає обраний файл для deep link виду `https://t.me/<BOT_USERNAME>?start=lead_<slug>`.

| Slug | Лідмагніт |
|---|---|
| `prompts` | 25 промптів для продажів |
| `first100` | План першого $100 з AI |
| `freelance` | Профіль фрілансера, що продає |
| `content` | 30 днів контенту за 30 хвилин |
| `research` | Дослідження клієнта з AI |
| `visual` | Візуали, що продають |
| `automation` | 7 автоматизацій для соло-бізнесу |
| `product` | Упакуй експертизу в продукт |
| `email` | Email-серія, що веде до продажу |
| `pricing` | Ціна та відповіді на заперечення |

Команда `/gifts` показує всі варіанти в боті. Налаштуйте `BOT_USERNAME`, щоб посилання стали доступними.
